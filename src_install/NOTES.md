# src_install - developer notes

The installer that keeps Balatro's files out of balatro_c releases (like the 3DS Half-Life port:
the user supplies the game data from their own copy). The .3dsx is standalone and can be
downloaded on its own; the script puts it and the assets in place.

## Files

- `install_balatro_c.sh` - finds the user's Steam copy of Balatro (Linux, Steam Deck, Flatpak/Snap
  Steam, macOS, Windows via Git Bash/MSYS2/WSL; every library in `libraryfolders.vdf`; requires
  `appmanifest_2379780.acf` unless `--game` is given), checks `version.jkr` is 1.0.1o, extracts the
  asset set the game expects (1x textures, sounds, shaders, fonts except the GoNoto fallbacks,
  localization) with unzip / python3 / bsdtar, finds the SD card (a mounted volume with `/3ds`), and
  copies everything to `sdmc:/3ds/balatro_c/assets/` plus `balatro_c.3dsx` next to it.
  `--azahar` targets the Azahar emulator's virtual SD card instead (`${XDG_DATA_HOME:-~/.local/share}/azahar-emu/sdmc`,
  the Flatpak's `~/.var/app/org.azahar_emu.Azahar/data/azahar-emu/sdmc`, macOS `~/Library/Application Support/Azahar/sdmc`,
  Windows `%APPDATA%/Azahar/sdmc`; the user folder must exist, `sdmc/3ds` is created). `--sd` overrides the path. The copy goes
  to `assets.new` first and replaces `assets` only when complete.
- `README.md` - for users; goes in the release zip.

## On the SD card

```
/3ds/balatro_c/balatro_c.3dsx
/3ds/balatro_c/assets/resources/...       Balatro's files (from the user's copy)
/3ds/balatro_c/assets/localization/...
/3ds/balatro_c/assets/balatro_c_assets.txt  marker: "balatro_c assets", format=1, game_version=1.0.1o-FULL
/3ds/balatro_c/settings.jkr, 1/ 2/ 3/      saves
```

## Game side (src_3ds)

- Reads assets from `ASSET_DIR` (`sdmc:/3ds/balatro_c/assets`, main.c); romfs holds only a note.
- `game/asset_list.c` lists the 188 expected files (generated by `src_3ds/tools/gen_asset_list.sh`
  from `../src_lua`; regenerate it if the copied set changes, and keep it in step with this script).
  With fewer than 80% present the game shows `assets_lockout` (system font) instead; debug key
  `FORCE_NOASSETS=1` forces it. The marker file is informational for now.
- START / SELECT use the game's own "+" / "-" glyphs, so no game art is modified or shipped.
